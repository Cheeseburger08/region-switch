# Changelog

## 1.3 — first public release

- Per-app profiles for 202 countries and territories.
- Searchable country picker with flags, alphabetical sections, and highlighted current selection.
- Individual app switches, global pause/enable, and manual refresh.
- SIM/network country and operator overrides, plus Galaxy Store cached-region overrides.
- Background Frida controller, Android control app, and optional test app.
- Public build instructions, existing-root installer, and third-party notices.

This release packages the existing S22 experiment. Broader device/root-manager compatibility has not been established.
